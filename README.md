# Actividades HCM

Actividades interactivas de inglés para los cadetes de 3er año de la Licenciatura
en Administración Militar — Heroico Colegio Militar, Campo Militar 1-C.

Prof. Civ. Brian Martínez Rodríguez.

Cada archivo `.html` es una actividad completa: abre en cualquier navegador,
funciona en el celular, no necesita internet ni instalar nada, se califica sola
y trae la clave del docente.

| Archivo | Lección | Contenido |
|---|---|---|
| `index.html` | — | Índice de todas las actividades |
| `leccion-05-vocabulary.html` | 5 | Vocabulary (Student Text pp. 51–56) |
| `leccion-04-indirect-commands.html` | 4 | Indirect commands and requests |

## Para agregar una actividad nueva

1. Sube el archivo `.html` nuevo a este repositorio.
2. Agrega su tarjeta en `index.html`, copiando el bloque `<a class="act">` de otra.
